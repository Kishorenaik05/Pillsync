# PillSync - Workflows & Wireframes

## Core Healthcare Workflow

### 1. Patient Workflow
- **Registration**: Patient signs up for an account.
- **Profile Creation**: Patient fills out demographic and basic medical history.
- **Dashboard**: 
  - Views a summary of their medication schedule (Placeholder for now).
  - Can edit their profile.

### 2. Caregiver Workflow
- **Registration**: Caregiver signs up for an account.
- **Profile Creation**: Caregiver fills out contact information.
- **Dashboard**:
  - Views assigned patients and their basic status (Placeholder for now).
  - Can edit their profile.

### 3. Admin Workflow
- Manages all users (roles, active status).
- Has oversight over patient-caregiver linkages.
